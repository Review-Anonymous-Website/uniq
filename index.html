Robot-learning safety filter

UNIQ: Type-Aware Input Correction

UNIQ filters nominal robot-learning inputs under mixed equality and inequality constraints. Equalities keep bilateral correction, while inequality rows use one-sided correction so safe-side motion is not pulled back toward a boundary.

Constraint semantics

Equality targets and inequality safe regions enter the correction layer with different row types.

Online correction

The layer modifies the nominal controller or learned policy output before execution.

Evaluation scope

The videos cover simulation comparisons and bounded physical robot demonstrations.
